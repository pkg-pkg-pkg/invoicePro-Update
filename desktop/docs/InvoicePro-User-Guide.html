InvoicePro User Guide

Version: 1.0.0

1) Download and Install

  1. Download GST Billing Software Setup 1.0.0.exe.
  2. Run installer and complete setup.
  3. Open app from desktop shortcut or Start Menu.

2) Activate License

  1. Open app and go to Activate screen.
  2. Enter activation key and required business details.
  3. Click Activate and wait for success message.

3) Login

  1. Enter registered email and password.
  2. Click Login.
  3. Use Forgot Password if needed.

4) Main Navigation

  • Accounts
  • Party Master
  • Vouchers
  • Expenses
  • GST
  • Reports
  • Settings

5) Recommended First Setup

  1. Create Ledger Accounts
  2. Create Godowns
  3. Create Inventory Items
  4. Create Party Master entries

6) Voucher Flow

  • Sales Voucher: Vouchers > Sales Vouchers
  • Purchase Voucher: Vouchers > Purchase Vouchers
  • Payment/Receipt: respective voucher menus
  • Journal Voucher: debit total must equal credit total

7) Reports and GST

  • Use date filters before viewing/exporting reports.
  • Check GST sections for compliance reporting.

8) Backup and Support

  • Take regular backups.
  • For support share screenshot, app version, and error steps.
