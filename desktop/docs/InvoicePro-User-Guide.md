# InvoicePro User Guide

## 1) Download and Install

1. Download the installer file: `GST Billing Software Setup 1.0.0.exe`.
2. Double-click the installer.
3. Click `Next`, choose install location, and finish setup.
4. Launch the app from desktop shortcut or Start Menu.

## 2) First Launch

1. Open `InvoicePro - GST Billing Software`.
2. If license is not activated, you will see the activation flow.
3. Keep internet ON for first activation.

## 3) Activate License

1. Go to `Activate` screen.
2. Enter:
   - Activation key
   - Business details (if prompted)
3. Click `Activate`.
4. Wait for success message.

If activation fails:
- Re-check key
- Check internet
- Contact support with screenshot

## 4) Login

1. Open app.
2. Enter registered email and password.
3. Click `Login`.
4. If forgotten password, use `Forgot Password` flow.

## 5) Basic Navigation

- Left menu:
  - Accounts
  - Party Master
  - Vouchers
  - Expenses
  - GST
  - Reports
  - Settings
- Top-right:
  - User profile
  - Logout

## 6) Create Masters (recommended order)

1. Ledger Accounts
2. Bank Accounts
3. Godowns
4. Inventory Items
5. Party Master (Customers/Suppliers)

## 7) Create Sales Voucher

1. Open `Vouchers > Sales Vouchers`.
2. Click `New Invoice` (or `Guided Invoice`).
3. Select customer and items.
4. Verify totals and taxes.
5. Save voucher.

## 8) Create Purchase Voucher

1. Open `Vouchers > Purchase Vouchers`.
2. Click `New Purchase Voucher`.
3. Add supplier + items.
4. Save.

## 9) Payment / Receipt / Journal

- Payment: `Vouchers > Payment Vouchers`
- Receipt: `Vouchers > Receipt Vouchers`
- Journal: `Vouchers > Journal Vouchers`

For Journal:
1. Add at least two ledger entries
2. Debit total must equal credit total
3. Save

## 10) Reports

- Sales, purchase, stock, GST reports are available from `Reports` and `GST`.
- Use date filters before exporting/printing.

## 11) Backup and Safety

1. Take regular backups.
2. Keep installer and activation key in safe location.
3. Do not share admin credentials.

## 12) Troubleshooting Quick List

- App not opening: restart system and relaunch.
- License issue: verify internet and activation key.
- Voucher save error: check mandatory fields.
- Print issue: verify printer setup.

## 13) Support Template

When contacting support, share:
- App version
- Screenshot of error
- Steps to reproduce
- Business name and registered email
